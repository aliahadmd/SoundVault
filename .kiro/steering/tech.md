# Tech Stack & Build

## Language & UI
- Kotlin (JVM target 11, configured through `kotlin { compilerOptions { … } }`)
- Jetpack Compose with Material 3, using the app's own Light / Night palettes (no dynamic color)
- Kotlin code style: `official`

## Key Libraries
| Library | Purpose |
|---|---|
| Media3 ExoPlayer 1.4.1 | Audio playback engine (owned by `PlaybackService`) |
| Media3 Session 1.4.1 | `MediaSessionService`, media notification, lock-screen controls, `MediaController` for the UI |
| AndroidX DataStore Preferences | Persisting folder, playback state and theme |
| AndroidX Room 2.7 (KSP) | Timestamp bookmarks database |
| AndroidX Lifecycle (runtime-ktx, runtime-compose) | Lifecycle-aware coroutines & state collection |
| AndroidX Activity Compose | Compose integration with Activity |
| Compose Material Icons Extended | Icon set (unused icons are removed by R8 in release) |
| Kotest (runner, property, assertions) | JVM unit and property tests on the JUnit Platform |

## Build System
- Gradle with Kotlin DSL (`.gradle.kts`), version catalog at `gradle/libs.versions.toml`
- AGP 9.1.1, Kotlin 2.2.10, KSP 2.3.2, Gradle 9.3.1
- `android.builtInKotlin=false` / `android.newDsl=false` in `gradle.properties` because the project still applies `org.jetbrains.kotlin.android` explicitly
- Single `:app` module

## SDK Targets
- `minSdk` 31 (Android 12)
- `targetSdk` / `compileSdk` 36

## Build Types
- `debug` – debuggable, not minified
- `release` – R8 minification and resource shrinking; signed only when the signing properties below are set, otherwise `app-release-unsigned.apk`
- `qa` – same as `release` but signed with the debug key and suffixed `.qa`, for testing minified builds on a device

## Common Commands
```bash
./gradlew assembleDebug             # Debug build
./gradlew assembleRelease           # Release build (R8)
./gradlew assembleQa                # Minified build installable for testing
./gradlew testDebugUnitTest         # JVM unit/property tests (kotest)
./gradlew connectedDebugAndroidTest # Instrumented tests (Room DAO) on a device
./gradlew clean
```

## Signing
Release signing is configured outside the repository through Gradle properties or environment variables:
`SOUNDVAULT_RELEASE_STORE_FILE`, `SOUNDVAULT_RELEASE_STORE_PASSWORD`, `SOUNDVAULT_RELEASE_KEY_ALIAS`, `SOUNDVAULT_RELEASE_KEY_PASSWORD`.
Keystores and password files are git-ignored (`keystore/*.jks`, `*.keystore`, `keystore/*.pass`) and must never be committed.

## Release Scripts
- `scripts/create_tag.sh [version]` – annotated tag; version defaults to `versionName`
- `scripts/publish_github_release.sh [version] [notes-file]` – uploads the signed APK; notes are generated by GitHub unless a file is given
